From Risk Classification to Action Plan Remediation:
A Guardrail Feedback-Driven Framework for LLM Agents

Yuhao Sun, Jiacheng Zhang, Shaanan Cohney, Zhexin Zhang, Feng Liu, Xingliang Yuan

Paper Code arXiv

Overview

We introduce TRIAD, a planning-stage guardrail framework that uses verbal feedback and three-way decisions to guide LLM agents to revise unsafe plans while preserving benign tasks.

Key Idea

Instead of treating guardrails as binary allow-or-block classifiers, TRIAD integrates guardrail feedback into the agent planning loop. The guardrail produces one of three decisions: Proceed, Update, or Refuse. The Update decision guides the agent to revise compromised action plans before tool execution.
